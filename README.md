# Russian 0.2.0 — русификация BB

Переводит описания, пояснения, подсказки и обычные служебные подписи. Названия плагинов, продуктов, моделей и авторов берёт из каталога BB и сохраняет в оригинале. Команды, код, ссылки и пути не переводит.

Новые элементы интерфейса и изменения текстов обрабатываются автоматически через официальный content script SDK BB. Плагин включается вместе с BB; запускать отдельный скрипт после обновлений не нужно. Исходники приложения и других плагинов не изменяются.

## Установка

```sh
npm ci --include=dev
npm run typecheck
npm test
bb plugin build .
bb plugin install . --yes
```

Настройки: **Настройки → Russian**. В списке плагинов плагин называется **Russian**.

```sh
bb russian status
bb russian status --json
bb russian disable
bb russian enable
bb russian translate "Run bb threads with Codex."
bb plugin config russian set online false
```

`enabled` включает русификацию, `online` — машинный перевод новых текстов; `preserve` — дополнительные названия, по одному в строке. Изменения применяются без перезапуска. При изменении исключений ранее применённые переводы пересматриваются; новые исключения действуют также на встроенный словарь. При отключении/удалении восстанавливаются оригиналы, если само приложение с тех пор не изменило соответствующий текст.

## Как работает перевод

Сначала применяется встроенный словарь проверенных текстов. Неизвестные пояснения переводятся через публичные неофициальные конечные точки Google Translate. Основная — `translate.google.ru`; резервные — `translate.googleapis.com` и `translate.google.com`. API-ключ не нужен, платные API не используются. Названия и технические фрагменты заменяются временными маркерами и проверяются при восстановлении. Результат с потерянным маркером не применяется. Форматированные пояснения переводятся как единая фраза: результат возвращается в существующие текстовые узлы, сохраняя ссылки, выделение и обработчики. Вложенные кодовые фрагменты остаются на месте и не отправляются переводчику. Если сервис переставил маркеры узлов, результат отклоняется.

Сетевые запросы выполняются на сервере BB последовательно для всех окон. Выключение сетевого перевода отменяет выполняющиеся запросы и запрещает запуск следующих частей очереди. Уже отправленные сервису данные отменой запроса отозвать нельзя. Ключ кеша включает версию правил защиты и список исключений: переводы, созданные старыми правилами, повторно не применяются. Результаты хранятся в собственной SQLite-базе плагина (до 20 000 записей), отдельно от проектов. Без сети работают словарь и сохранённые переводы. Если сервис недоступен, остаётся оригинал; попытка повторяется автоматически через минуту. Для перевода нового текста нужен интернет, поэтому абсолютной полноты и мгновенного перевода нет.

## Границы

- Переписка, терминалы, код, редакторы, значения полей, содержимое сайтов в Browser, изображения и системные меню macOS исключены.
- Неизвестные короткие строки, заголовки и имена остаются оригинальными. Это защита от переименования продукта. Дополняйте словарь для новых коротких служебных подписей.
- Изменение разметки BB может потребовать обновления селекторов в `dom.ts`. Плагин не обещает полной совместимости со всеми будущими версиями.
- Перевод автоматический и может содержать неточности. Исходные тексты сохранены для обратимого отключения.
- На сервер перевода отправляются новые пояснения интерфейса. Чувствительные элементы собственных плагинов исключайте через `translate="no"` или `data-bb-russian-skip`.

## Проверки

29 проверок `npm test` покрывают R1–R5 и регрессию: динамическое появление и обновление текста, сохранение обработчиков кнопок, исключение переписки/кода/редакторов, обратимость, запоздалые ответы, защиту технических фрагментов, валидацию RPC и публичный SDK. Для диагностики реального окна: `bb russian status --json` и `bb plugin logs russian`.
